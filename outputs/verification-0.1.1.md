# 花间 v0.1.1

这次增加了两项操作：

- 选择启动程序后自动填写游戏名，去掉 `.exe`。`game.exe`、`start.exe`、`launch.exe`、`launcher.exe`、`main.exe`、`play.exe` 使用游戏目录名；手动填写和已收藏的名称不会被覆盖。重新选择程序时，尚未手动改过的自动名称会同步更新。
- 网格、列表中的游戏卡片都可拖到侧栏“想玩 / 在玩 / 已通关 / 搁置”修改状态，目标区域会高亮。成功保存才更新列表和计数；保存失败保留原状态。

## 验证

完整测试 7 个文件、43 项通过，类型检查和生产构建通过。

Mac 实际 Electron 窗口中，模拟文件选择器选择真实存在的测试 .exe 路径，确认名称自动从 Summer 改为“夏日回忆”；使用真实鼠标拖拽事件，从网格拖到“在玩”，再从列表拖到“已通关”，两次均确认本地库已保存对应状态。文件选择对话框被自动化替代，选后路径检查与保存走真实桌面接口。

Windows ARM64 便携包已重新构建。Windows 图形界面、真实游戏启动仍待用户登录虚拟机后验证。

## 使用

完整解压 `Hanami-0.1.1-windows-arm64.zip`，运行其中的 `Hanami.exe`。使用同一 Windows 用户时，原有书架仍从原数据目录读取，无需重新导入。请关闭旧版后再打开新版。

源码见 `Hanami-0.1.1-source.zip`，开发命令见其中的 `app/README.md`。原始架构与初版验证记录保留在设计文件和 `verification.md` 中。
