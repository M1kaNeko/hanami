# 花间 v0.1.3

选择启动程序后，默认提取 exe 内的图标，居中放在带留白的封面上。手动选择的封面优先保留；更换程序时只刷新自动图标，直接填写 exe 路径也支持。提取失败则保留文字占位，不妨碍添加游戏。提取图标不会启动游戏，确认保存时才写入封面。

已有记录不会批量补图或覆盖；编辑时重新选择启动程序即可生成。目录名默认命名、拖拽状态、三套配色继续保留。

## 验证

- 8 个测试文件、53 项测试全部通过，类型检查和生产构建通过。
- 覆盖图标合成、失败回退、手动封面优先、异步旧请求隔离、直接输入路径、更换自动封面等情况。
- Mac 实际 Electron 中，使用真实 NativeImage 验证缩放、PNG 保存、封面协议解码及来源字段持久化；系统图标入口使用测试适配器替代。
- Mac 实际 Electron 中验证目录名命名、网格与列表鼠标拖拽保存、配色和重启保留。
- Windows ARM64 便携包已生成；Windows 系统读取 exe 图标、界面及真实游戏启动仍待虚拟机实测。

## 使用

关闭旧版，完整解压 `Hanami-0.1.3-windows-arm64.zip`，运行其中的 `Hanami.exe`。左下角确认 v0.1.3。原书架沿用同一 Windows 用户的数据目录。

源码：`Hanami-0.1.3-source.zip`。运行和构建见 `app/README.md`。
