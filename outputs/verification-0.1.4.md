# 花间 v0.1.4

## 本次功能

新增“内置吉里吉里 Z”启动方式。添加或编辑游戏时选择该模式，再选完整游戏目录即可，不要求 exe。启动时依次寻找 `startup.tjs`、`data/startup.tjs`、`data.xp3`，通过随包提供的 Windows 原生引擎在独立窗口运行。直接启动 exe 的原有方式保留，旧记录默认沿用。

内置运行时为官方 Kirikiri Z 1.4.0r2 的 32 位版本及同包的 32 位插件。主程序仅由 tvpwin32.exe 改名为 krkrz.exe，二进制内容未修改；来源与本地校验值见 `resources/engines/kirikiri/provenance.json`，原始说明及许可保留。来源：[官方发布页](https://krkrz.github.io/)。

默认存档目录为花间用户数据目录中的 `saves/<收藏ID的SHA256>/`，每条记录独立。移出收藏不会删除存档，游戏脚本另行指定存档位置时可能不同。原 exe 存档不会自动迁入；书架备份仍只包含清单和封面，不包含存档。

- 9 个测试文件、61 项测试通过，类型检查、生产构建通过。
- 验证启动参数、缺失入口/引擎回退、空 exe 的模式校验、目录去重、旧记录兼容及备份恢复保留启动方式。
- Mac 实际 Electron：走真实桌面 IPC，并将主进程平台值替换为 win32 验证 Windows 保存分支；添加、持久化与重新编辑内置启动方式成功。
- Windows 11 ARM 虚拟机：使用便携包内的 Electron 运行实际服务模块，添加并启动自己编写的最小 TJS 测试游戏；32 位引擎成功加载随包 menu.dll、创建 Window、执行脚本并退出。日志中验证测试标记位于该游戏独立的 saves 目录，最近启动时间已记录。该检查以系统会话运行，不等于真实桌面交互验收。
- Mac 实际 Electron 回归：目录名默认命名、网格/列表鼠标拖拽、三套配色及重启保留；NativeImage 图标缩放、封面保存与协议显示均通过。
- 尚未验证用户的真实游戏、视频/音频与全部第三方插件。加密归档、专用插件或定制引擎可能需要原 exe；此功能不是通用 galgame 模拟器。Windows 系统提取 exe 图标及完整桌面交互仍待真实游戏验收。

## 使用

关闭旧版，完整解压 `Hanami-0.1.4-windows-arm64.zip`，运行 `Hanami.exe`，确认左下角 v0.1.4。此包适用于当前 Mac 的 Windows 11 ARM 虚拟机。

添加游戏 → 启动方式“内置吉里吉里 Z” → 选择完整目录 → 保存 → 启动游戏。目录路径建议简短，内置模式最多支持 220 字符的游戏目录。

引擎随包提供，无需安装安卓模拟器或另行下载。请保留整个 resources 目录。源码包为 `Hanami-0.1.4-source.zip`，使用和构建见其中 `app/README.md`。

Windows 引擎自检脚本：设置 `ELECTRON_RUN_AS_NODE=1` 后，用便携包的 `Hanami.exe` 执行源码内 `app/scripts/windows-kirikiri-check.cjs`，第二个参数传便携包根目录。仅使用自建测试脚本，不读取真实游戏。该脚本将测试数据保留在 Windows 临时目录中供检查。
