# 花间 v0.1.2

## 本次调整

- 新增游戏默认使用所选游戏目录的最后一级文件夹名。选择、更换启动程序均不会用 exe 文件名替换目录名；手动修改和已有记录的名字保留。
- 右上角调色盘提供青苔绿、樱花粉、雾蓝三套配色，调整窗口背景、侧栏、主要按钮、选中项及拖拽高亮，并记住上次选择。
- v0.1.1 的网格/列表拖拽状态功能保留。

## 实际验证

7 个测试文件、45 项全部通过；类型检查和生产构建通过。

Mac 实际 Electron 窗口中，选择目录“夏日回忆”及其中的 `Engine.exe`，确认名称仍为“夏日回忆”。文件对话框由自动化替代，实际文件、路径检查和保存使用真实桌面接口。

使用真实鼠标拖拽事件将卡片从网格拖到在玩，再从列表拖到已通关，确认两次本地保存成功。切换粉色与蓝色，等待颜色过渡结束后检查真实计算样式并截图；关闭重开确认雾蓝仍保留。

Windows ARM64 便携包已重新生成，Windows 图形界面与真实游戏启动仍待虚拟机实测。

## 使用

关闭旧版，完整解压 `Hanami-0.1.2-windows-arm64.zip`，运行其中的 `Hanami.exe`。左下角应显示 v0.1.2。原书架沿用同一 Windows 用户的数据目录，已有名称不会批量修改。

源码：`Hanami-0.1.2-source.zip`。运行与构建方法见其中 `app/README.md`。
